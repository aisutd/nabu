# Nabu

## Description

Nabu is an AI-aided language learning platform that gives users a personal tutor for practicing speaking, reading, and writing. It uses conversation, handwriting and pronunciation analysis, and behavioral signals to adapt lessons around each learner's needs.

## Planned Technologies

- Python, JavaScript, and SQL
- React, TypeScript, and Tailwind CSS
- PyTorch, OpenCV, MediaPipe, and PostgreSQL
- GPT, ElevenLabs, and Supabase APIs

## Docker Setup

Make sure Docker Desktop is installed and running.

```bash
docker compose up -d
docker compose down
docker compose ps
```

This is a generic starter configuration. The team can add project-specific dependencies and startup commands later.
